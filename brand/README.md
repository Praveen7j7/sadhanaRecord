# IYF Delhi logo files

Made from the official logo `iyf logo (full)-01.png` (885 × 280). Nothing is redrawn: the original was enlarged 4×
with the Real-ESRGAN AI upscaler (model `realesrgan-x4plus-anime`, best for clean edges), so colours, gloss and shapes
are the official logo's own. These are the highest-resolution copies there are; use them anywhere.

| File | Size | Use |
|---|---|---|
| `iyf-logo-full-3540x1120.png` | 3540 × 1120, transparent | The full logo (emblem + "ISKCON Youth Forum, Delhi"), print and large screens |
| `iyf-logo-full-3540x1120-white.jpg` | 3540 × 1120, white background | Where transparency is not supported |
| `iyf-logo-full-original-885x280.png` | 885 × 280 | The original, unchanged |
| `emblem/iyf-emblem-892.png` | 892 × 892, transparent | The round IYF emblem alone (largest) |
| `emblem/iyf-emblem-512/256/128/64.png` | | Smaller copies of the emblem |
| `app-icons/icon-*.png`, `maskable-*.png` | 192, 512 | Installed-app icons (emblem on the royal-purple tile) |
| `web/favicon-32/48/192.png`, `apple-touch-icon.png` | | Browser-tab and iPhone home-screen icons |
| `web/og-image.jpg` | 1200 × 630 | The preview shown when the app link is shared (WhatsApp, Telegram, …) |

The Sadhana app uses the emblem from `frontend/public/brand/` (WebP, 64 to 512 px, picked by screen sharpness), so it
is never shown larger than its real resolution.
