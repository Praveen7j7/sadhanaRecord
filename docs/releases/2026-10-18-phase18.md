## What shipped

| Area | Change |
|---|---|
| IYF IDs | Only `IYFD-<connected year>-NNNN`, issued by the identity authority's per-year sequence (`identity.issueForAccount`). The global-MAX counter that could reissue numbers is gone. No year → no ID: approval still goes through and the head is told a year is needed. |
| Connected since | A legacy user (GP26-, JN26-, KT26-, SR26-) sets **Connected since** once in About you; a new IYFD is issued and the old ID is superseded (it still resolves). Locked once set, or once an IYFD exists. |
| IYF IDs › Created here | The head picks the connected year when creating an ID; the preview shows the next number for that year. |
| Devices | Account › Devices lists every signed-in device ("Android · installed app", "Mac · Chrome"), this one first; any of them can be signed out. |
| Icons | `docs/ICON_SCOPE_AUDIT_2026-10-18.md` implemented: card measure icons, History and Week row icons, sign-up section icons, Forgot, Students, Scoreboards rank chip, Closing choices, Reopens. Two dead icons removed (`body`, `pause`). |
| Close batch (ETP) | The screen offers **Qualified / Repeat / Left** and "Everyone qualified" for a training. It counts weeks present from the training's own marks. |
| Closing a training — server fix | Every enrolment now ends when a training closes, so the ETP section goes for everyone. Before, a **Repeat** kept an ACTIVE enrolment and the ETP tab for good. **Left** ran the class-batch path on an enrolment id: it ended an unrelated person's membership and switched the trainee's account off. Promoting out of a training is refused, even for the head (decision 47). No batch had ever been closed on live, so nothing needs repairing. |
| Approving with a new IYF ID | When the sign-up has no connected year, the card asks for **Connected since**, previews `IYFD-<year>-NNNN`, and approves with the ID in one step (`requests.approve` takes `link.year`). Before, it approved with no ID and said "the IYF ID will be linked automatically", which never happened. The stale "SR… series / add it to the dashboard" wording is gone. |
| Smaller fixes | Close batch rows padded, the choice named for screen readers; "students" for a training; IYF IDs tools in two rows under 400 px; explanatory sentence removed from IYF IDs. |
